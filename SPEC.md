# Apex — Project Specification

## Задача проекта

Apex — веб-сервис и мобильное приложение для изучения астрономии.
Три независимых инструмента под одним брендом:

1. **Генератор карт звёздного неба** — настраиваемые карты в формате PDF
   для наблюдений, олимпиад и уроков астрономии. Стереографическая и
   pinhole-проекции, экспорт с легендой и логотипом.

2. **Sky Quiz** — пять игровых режимов для изучения созвездий, звёзд
   и объектов каталога Мессье. Сессии, очки, стрики, ранги.

3. **AstraEtudes** — интерактивные физические симуляторы по астрономии
   (орбитальная механика, фазы луны, эффект Доплера и др.).

Целевая аудитория: школьники и студенты, педагоги астрономии, любители.
Языки интерфейса: русский и английский.

## Стек

### Shared Core — Rust (библиотека)

Ядро проекта. Используется сервером и мобильным приложением.

```
rust-core/
├── catalog/       ← HIP (Hipparcos), Messier, созвездия
├── projections/   ← стереографическая, pinhole, цилиндрическая
├── mechanics/     ← RK4 интегратор, орбитальные элементы
└── scoring/       ← логика очков, стрики, ранги
```

### Backend — Rust (Axum)

Минимальный сервер. Вызывается только там где нужна серверная логика.

| Endpoint | Что делает |
|---|---|
| `POST /api/export` | Генерация PDF через `plotters` крейт |
| `POST /game/api/*` | Game API: сессии, вопросы, ответы, scoring |
| `GET /api/compute` | Орбитальный симулятор (RK4 + конические сечения) |
| Static | Messier фото (110 JPEG) |

Персистентность: **SQLite** через `sqlx` (вместо текущего in-memory Python dict).
Целевое потребление памяти: **20–40 MB** в idle на Railway free tier.

### Web Frontend — SvelteKit

| Раздел | Технология |
|---|---|
| Landing page | Svelte компоненты, статика |
| Генератор | Canvas 2D — превью в реальном времени (JS). `POST /api/export` только при скачивании |
| Sky Quiz (web) | Svelte, Canvas для Draw режима |
| AstraEtudes | Svelte + Canvas для орбитального симулятора |

Каталог HIP загружается один раз при открытии генератора.
Все проекции для превью считаются локально в JS — сервер не задействован.

### Mobile — Flutter

Игры + упрощённый генератор. iOS и Android из одного кода.

**flutter_rust_bridge** — rust-core компилируется в нативный код:
- проекции считаются на устройстве, офлайн
- игровая логика без сервера

### Инфраструктура

| Сервис | Где |
|---|---|
| Rust сервер | Railway (free tier) |
| SvelteKit | Vercel (free tier) |
| Flutter Web | Vercel или статика с Rust сервера |
| SQLite | Volume на Railway |

### Dev tooling

```

pnpm           — JS / Svelte
flutter        — мобайл
cargo-watch    — hot reload Rust в dev
```

## Экраны

### Навигация

- **Web:** топ-бар (Генератор / Игры / AstraEtudes)
- **Mobile:** bottom nav (Главная / Генератор / Игры / Симуляторы)

### Landing

- Hero: название, подзаголовок, две CTA (Генератор / Игры)
- Секция инструментов: 4 карточки с описанием
- Секция игр: превью 5 режимов
- Секция симуляторов
- Футер

### Генератор

1. **Форма + превью** (ray.so layout)
   - Панель: проекция, место/время, слои, звёздная величина
   - Canvas превью обновляется в реальном времени
   - Кнопка "Скачать PDF" → loading → файл

2. **Loading** — индeterminate спиннер, пока сервер генерирует PDF

### Sky Quiz

1. **Лобби** — 5 карточек режимов с иконкой, описанием, тегами
2. **Pre-game setup** — сложность (Easy/Medium/Hard), кол-во раундов, язык, правила режима
3. **Game screen** — шапка (прогресс, счёт, стрик, таймер) + контент режима:
   - *Constellation / Trivia:* изображение + 4 варианта
   - *Star easy/medium:* изображение + 4 варианта
   - *Star hard:* изображение + ввод названия + интерактивная карта RA/Dec
   - *Messier:* фото объекта + ввод числа 1–110
   - *Draw:* canvas с точками-звёздами, рисуешь линии
4. **Round result** — ✅/❌, очки, breakdown, стрик-уведомление, fun fact, кнопка "Следующий"
5. **End game** — ранг, итоговый счёт, статистика (точность, лучший стрик), история раундов, share

### AstraEtudes

1. **Хаб** — карточки сценариев (активные + "Скоро")
2. **Орбитальный симулятор** — панель (скорость, угол, высота, пресеты) + канвас (RK4, коника, плоская Земля) + орбитальные элементы

### Глобальные

- **Настройки** — язык, тема, звук (mobile)
- **404** — тёмный, "объект не найден в каталоге"

## Scoring (сохранить из текущей реализации)

| Параметр | Значение |
|---|---|
| Базовые очки | Easy 100 / Medium 200 / Hard 350 |
| Стрик ×2 | от 2 подряд |
| Стрик ×1.5 | от 3 подряд |
| Стрик ×2.0 | от 5 подряд |
| Стрик ×3.0 | от 10 подряд |
| Time bonus | ×1.2 если ответ за 8 сек (45 сек для Draw) |
| Hint penalty | ×0.5 |

**Ранги:**

| Очки | Ранг |
|---|---|
| 0+ | 🌑 Beginner |
| 500+ | 🌙 Night Apprentice |
| 1500+ | 🔭 Sky Watcher |
| 3000+ | ⭐ Star Navigator |
| 5000+ | 🌌 Galactic Explorer |
